# Análise e Desenvolvimento de Sistemas (ADS)

Bem-vindo ao meu repositório do curso de **Análise e Desenvolvimento de Sistemas**!

Aqui estão reunidos os trabalhos, exercícios, atividades, projetos acadêmicos e materiais desenvolvidos ao longo da graduação.

Este repositório tem como objetivo documentar minha evolução durante o curso, reunir os conteúdos estudados e servir como portfólio do meu aprendizado.

## Sobre o repositório

Ao longo dos semestres são adicionados conteúdos relacionados às disciplinas do curso, incluindo:

* Exercícios propostos em aula;
* Trabalhos acadêmicos;
* Projetos desenvolvidos durante as disciplinas;
* Estudos complementares;
* Testes e experimentos.

> **Importante:** Projetos maiores, mais completos ou desenvolvidos além do escopo acadêmico possuem repositórios próprios no meu perfil.

## Conteúdos estudados

Entre os assuntos abordados durante o curso estão:

* Programação Orientada a Objetos
* Estruturas de Dados
* Algoritmos
* Banco de Dados
* Engenharia de Software
* Desenvolvimento Web
* APIs REST
* Redes de Computadores
* Sistemas Operacionais
* Arquitetura de Software
* Versionamento com Git e GitHub
* Outras disciplinas da graduação.

## Tecnologias

Tecnologias utilizadas até o momento:

* Java
* Python
* HTML
* CSS
* PostgreSQL
* SQL server
* Git e GitHub

## Organização

Os diretórios normalmente seguem a organização por semestre, disciplina ou conteúdo estudado, facilitando a navegação e a consulta dos materiais.

## Objetivo

Este repositório existe para:

* Registrar minha evolução durante a graduação;
* Compartilhar projetos e atividades públicas;
* Facilitar revisões futuras;
* Demonstrar meu desenvolvimento técnico ao longo do curso.
